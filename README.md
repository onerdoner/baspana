# Baspana

Сайт недвижимости по Алматы: продажа и аренда квартир, фильтры, карта, страницы объявлений, аккаунты и загрузка фото.

## Технологии
- HTML, CSS, JavaScript (ванильный, без фреймворков)
- Supabase — база данных, авторизация и хранилище фото
- Leaflet + OpenStreetMap — карта с кластерами

## Структура
- `index.html` — разметка страницы
- `css/styles.css` — стили
- `js/app.js` — вся логика

## Запуск локально
```
npx serve
```
Открыть http://localhost:3000

## Настройка
В `js/app.js` вверху вписать свои ключи Supabase:
`SUPABASE_URL` и `SUPABASE_KEY`.
